
# Tesla Stock Analysis

## Overview
This project focuses on analyzing Tesla stock data using Python.
It includes data cleaning, statistical analysis, data filtering, and
visualization of different stock attributes.

## Dataset
The dataset contains Tesla stock data from 2010 to 2020 with the following
attributes:
- Date
- Open
- High
- Low
- Close
- Adj Close
- Volume

## Libraries Used
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Analysis Performed
- Loaded the dataset into a Pandas DataFrame
- Checked the shape and data types of the dataset
- Checked missing values
- Calculated minimum and maximum values
- Calculated mean, median, and standard deviation
- Created a correlation heatmap
- Converted the Date column to datetime
- Filtered data using conditions
- Used `nlargest()` and `nsmallest()`
- Created line plots and bar plots
- Created histograms for data distributions
- Created scatter plots to study relationships between attributes

## Tools
- Python
- VS Code
- Jupyter Notebook

## Project Purpose
The purpose of this project is to practice Python data analysis and
visualization techniques using real-world Tesla stock data.
